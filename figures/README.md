# Figures and Visualizations

This folder contains charts generated during exploratory data analysis, logistics performance analysis, and model interpretation.

Examples of generated figures include:

- Shipping mode analysis
- Actual versus scheduled shipping duration
- Market-level shipping performance
- Actual versus predicted shipping duration
- Prediction error distribution
- Linear Regression coefficient analysis

The charts help communicate the analytical findings and model behaviour.

Figures are generated by the Python scripts and can be inserted into the internship report.
