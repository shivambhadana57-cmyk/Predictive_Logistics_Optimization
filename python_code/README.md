# Python Code

This folder contains the Python scripts developed for the Predictive Modeling and Optimization in Logistics Systems project.

## Main Workflow

1. Data loading and initial inspection.
2. Data preparation and feature selection.
3. Exploratory Data Analysis.
4. Model training using Dummy Regression, Ridge Regression, and Linear Regression.
5. Model validation and hyperparameter tuning.
6. Logistics performance and optimization analysis.
7. Model interpretation and coefficient analysis.

## Libraries Used

- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## Execution

Run the scripts from the project root directory using the project's Python environment.

Example:

`python python_code/02_data_preparation.py`

Follow the workflow order and ensure the required dataset and intermediate files are available before running each script.

The exploratory analysis script should also be run at the appropriate stage using its actual filename.

Refer to the main repository README for dataset download instructions and setup information.
