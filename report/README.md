# Project Report

This folder contains the documentation and supporting screenshots for the internship project.

The report covers:

- Project overview and objectives
- Tools and technologies
- Dataset description
- Data preparation and feature selection
- Exploratory Data Analysis
- Model development and evaluation
- Logistics performance analysis
- Model interpretation
- Business recommendations
- Challenges, limitations, and conclusion
- References

The `screenshots/` folder is intended for selected screenshots of Python outputs and generated visualizations.

The final report may be shared as a DOCX or PDF file, depending on the internship submission requirements.
