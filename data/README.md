# Data Folder

This folder contains the dataset organization used in the project.

## Folder Structure

- `raw/` – Location for the original DataCo SMART Supply Chain CSV dataset.
- `processed/` – Location for prepared modelling data and generated analytical results.

## Dataset Source

The dataset was obtained from Mendeley Data:

https://data.mendeley.com/datasets/8gx2fvg2k6/5

The original dataset is not included in this public repository. Download it from the source and place it in the `raw/` folder before running the project scripts.

## Note

Raw customer-level data and sensitive records should not be uploaded to GitHub. Processed files should also be reviewed before public sharing.
