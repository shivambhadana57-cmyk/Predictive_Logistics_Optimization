# Processed Data

This folder stores the outputs generated during data preparation, modelling, validation, and logistics performance analysis.

Examples of generated outputs include:

- Prepared modelling dataset
- Model evaluation results
- Model validation results
- Test predictions
- Optimization analysis results
- Model interpretation results

These files are generated by the Python scripts. They are not required to be uploaded to the public repository, particularly if they contain row-level records or other information that should remain private.
